# MIXXTOPIA 隐私说明

> 适用：账户与云存档功能（Issue #22 / #42）上线后。
> 设计依据：`docs/ACCOUNT_SYSTEM.md` §10；实现：`supabase/migrations/0001_init.sql` / `0002_stats.sql` + `js/cloud-config.js`。
> 一句话：**游客游玩的进度零上传；账户功能用于跨设备同步，主动申请密码找回时会发送认证所需信息。**

## 1. 我们收集什么

| 数据 | 用途 | 何时产生 | 是否必需 |
|---|---|---|---|
| 邮箱 | 登录凭据（由 Supabase Auth 托管） | 注册 | 是 |
| 昵称（1–16 字） | 账户页展示 | 注册默认值，可在设置里改 | 否 |
| 头像 id（固定选项集的标识，如 `muse-1`；**不支持上传图片**） | 账户页展示 | 设置 | 否 |
| 偏好（声音开关、触屏虚拟按键显示模式） | 跨设备同步设置（设备级：新设备首次登录采用一次） | 点击账户设置「保存设置」时同步云端；标题声音开关/设置页即时切换仅写本机 | 否 |
| 存档进度（当前关、已收集星、已通关、黑羊计数、已播对话节点） | 换设备继续玩 | 保存并退出 / 通关自动存档 | 是（云存档的前提） |
| 统计（游玩时长、成就、收集率） | 账户页展示 | 仅游玩时累计时长；登录、保存、回标题或查看账户时同步，离线下次补传。游客时长与成就仅存本机，不自动并入账号 | 否 |
| 请求日志（IP、时间、状态码） | 故障排查与防滥用 | 每次请求 | 由后端自动产生 |

## 2. 我们不收集什么

真实姓名、手机号、住址、支付信息、精确位置、相册、通讯录、设备指纹。

**不接入任何第三方分析或广告 SDK**（无 Google Analytics、无埋点、无像素追踪）。

## 3. 存在哪里、经过谁

- **Supabase**（Postgres + Auth）作为数据处理方，数据库在你创建项目时选择的区域（Singapore 或 Tokyo）；
- 密码重置邮件通过部署配置的自定义 SMTP 或 Send Email Hook 发送，邮箱地址和一次性重置链接会经过配置的邮件服务；正式通道的邮件服务商以部署配置为准；
- 所有请求走 **HTTPS**；
- 本地 `localStorage`（`mixxtopia.save.v1`、`mixxtopia.settings.v1`、`mixxtopia.cloud.v1`）**只存在你自己设备上**；其中 `mixxtopia.cloud.v1` 保存逐档同步基线和已授权存档快照；`mixxtopia.stats.v1.*` 保存按账号区分的统计待补传记录与云端统计缓存，beta/preview 使用各自通道键；
- 统计使用每个页面随机生成的计数标识避免重复上传，不读取硬件、浏览器特征或设备指纹；云端仅保留这些计数与游戏所需统计；
- 静态页面由 **GitHub Pages** 托管。

## 4. 未登录时

主动使用「忘记密码」时，申请表单会把邮箱发送给账户认证服务以请求重置邮件；点击邮件链接后，独立页面验证身份并提交新密码。恢复令牌仅在该页内存中使用，不写入游戏登录态，不读取或修改本机游戏存档、设置或统计；重置完成后返回游戏登录。详情见 [邮件找回密码说明](PASSWORD_RECOVERY.md)。

**游客游玩时进度零上传。** 所有游戏进度只写本机 `localStorage`；注册、登录和主动申请密码找回所需的认证请求除外。

## 5. 保留与删除

- 数据保留到账号被删除为止；
- 账户设置里已提供「删除账户（提交申请）」入口（Issue #44）：跳转预填说明的 GitHub issue 模板，提交申请后由维护者在 Supabase 后台删除 `auth.users` 记录（前端只有公开密钥，不能执行该操作），`profiles` / `saves` / `stats` 由外键**级联删除**，不可恢复；
- 若入口出问题，可在本仓库开 issue 提出删除请求：**只写「申请删除账户」，不要附邮箱或其他个人信息**；维护者会回复并安排身份核实，不会要求你在公开 issue 中提供邮箱。

## 6. 你的权利

| 权利 | 做法 |
|---|---|
| 查看 | 账户设置页展示昵称 / 头像 / 偏好 / 统计；存档在游戏内可见 |
| 更正 | 账户设置页修改 |
| 删除 | 账户设置页「删除账户」（提交申请）；入口不可用时开 issue 提出不含个人信息的请求 |
| 导出 | 后续可加「导出存档 JSON」（#47 视需要） |

## 7. 未成年人

本游戏不面向 13 岁以下儿童，也不主动收集年龄信息。未成年人建议在监护人知情同意下使用；监护人若发现孩子注册了账号，可通过仓库 issue 提出删除请求（不要公开孩子的账号邮箱或其他信息），维护者会安排核实与处理。

## 8. 变更

本文件随仓库提交，历史可在 `git log -- docs/PRIVACY.md` 查看。涉及收集范围的重要变更会在游戏内提示一次。
