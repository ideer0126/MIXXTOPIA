# 长廊玩法与地图改进 · 2026-11-19

本轮把「向右走、等敌人靠近、站着攻击」改为「观察预告 → 走位 / 闪步 / 打断 → 利用环境 → 点灯休整」。为本地第一轮实现，乐趣与节奏仍需玩家试玩评价。

## 战斗

- PC Shift / 触屏 D：沿输入朝向闪步 48px（三格），斜向等距离。冷却 1.1 秒，无敌 0.18 秒；逐段检测墙和关闭的门，不可穿门。底部持续显示就绪 / 冷却。
- 灰烬团：进入 30px 后停步，橙圈预警 0.6 秒，再攻击固定的 24px 半径范围；之后休整 0.8 秒。
- 火灵：88px 内且视线可达时，蓝圈锁定玩家当时的位置；0.9 秒后攻击 20px 半径，之后休整 1.1 秒。落点不会随玩家追踪。
- G 重击与能量炮会打断蓄力，敌人休整 0.8 秒。F 轻击保留原快速攻击用途。
- 全部出招保留原受伤无敌帧，不再使用长廊的接触碰伤。其他关卡战斗行为保持原样。
- 第一次点亮各灯柱时恢复全部生命、补充 35 能量（上限 100），亮灯后不能反复刷补给。三灯补给由原点灯进度自然限制；读档仍重置战斗资源。
- 三张镜阵、E 手动选镜 / H 不改选 / 三灯 J、保存版本 3/5/2 保持。

## 地图

主通道仍为 240 格长、11 格等宽，无侧室、凹位或局部加宽。机关门仍保留原单格门口。

- x2–59 冷石引导段：单只近战，第一组喷口贴北侧，南侧可绕行。
- x61–129 铜炉段：铜色地板 / 金属嵌条，x88 近战与 x96 火灵组合；南侧喷口 x91–93，北侧可绕行，也可以把敌人引入喷口。
- x131–199 青铜水纹段：青色地板 / 细水纹，x156–158、y8–12 中部喷口，上下两侧均留空，要求提前选路线。
- x201–237 星纹段：紫色地板 / 星纹，x218 与 x222 上下火灵形成交叉落点；末段仍可探索北墙第四星。
- 两侧实墙增加嵌窗、设备面板和金属墙带，贴墙行走不再看到大片空黑。装饰均绘在实际墙格或作为平面地纹，无额外阻挡。

四组喷口以 5 秒循环运行：休息 2.8 秒、黄闪预警 1.2 秒、喷发 1 秒；每轮对玩家至多伤 1 HP，对每只敌人伤 2 HP 并打断蓄力。初始敌人、油、灯、星与入口均不占喷口。喷口不堵满通道，棋盘 / 对话 / 暂停冻结其周期。
