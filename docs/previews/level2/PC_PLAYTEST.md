# 第二关 PC 试玩验收

2026-11-16 · 常驻引导版，本地自动验收完成，尚未提交 / 发布。按用户选择以 PC 为本轮目标；没有将触屏模拟记作手机实测。

## 打开试玩包

运行 `node tools/build-pc-playtest.js` 会在仓库的 `.ds/pc-playtest/` 生成 `MIXXTOPIA-PC-Playtest.zip` 与 SHA-256 文件。解压整个目录后：

- 推荐打开 `kerosene-guided.html`，标题标示「第二灯分组 · 手动解谜」，点击「新游戏」进入第二关。原 `kerosene.html` 同步更新，两个第二关入口共用试玩存档。
- 打开 `index.html`，从序章体验第一关 → 第二关的完整衔接。
- WASD / 方向键移动，E / 空格 / Enter 互动，Esc 暂停。Esc →「保存并退出」后，下次用同一个入口的「继续冒险」。刷新会放弃未保存的进度。
- 战斗版：F 轻击、G 重击，能量满后任一攻击释放能量炮；共有五处遭遇。倒下回入口满血复起，保留油 / 灯 / 星。重玩或读档重置战斗状态。
- 解谜版：携油靠近灯柱按 E，切入独立光路棋盘。点击镜面会带动金框标出的其他镜面（第二灯按互不重叠的组整组转动），让火光按编号依次经过圆环灯芯，再进入方框出口；也可方向键 / WASD 选镜，E / 空格旋转、G 撤销、F 重置。默认显示操作规则；E 只旋转玩家选中的镜面，不自动改选。三个灯柱都可主动按 H 查看建议，或按 J /「帮一步」执行建议一步，G 可撤销。接通后按 E 或点击「点灯返回」。Esc /「返回长廊」退出，不耗油。

两个入口分别使用独立的三个试玩存档位，与原游戏的 stable / beta / preview 存档隔离。本地试玩不连接账户或云存档；完整原始游戏代码由现有 `tools/build-site.js` 构建，快捷入口和试玩存储适配仅存在于生成的包中。项目正式入口与选关规则没有修改。

## 本轮自动验收

`tools/smoke-pc-playtest.js` 构建 ZIP、检查压缩完整性，解压后核对全部 45 个文件的列表和 SHA-256，再对解压产物运行 PC Chrome 检查。

| 完全离线 | 1280×720 | 1 | 解压包 `file://`，浏览器网络关闭 | 通过 |

- Playwright 键盘事件驱动实际 rAF 游戏循环，验证 W 与方向键移动、E 互动、空格快进、Enter 翻页、Esc 暂停及继续；失焦清除移动输入。
- 战斗版另用实际 F / G 键分别打出轻击、重击和能量炮并核对击败敌人；满能量与低血量作为测试前置夹具，真实接触伤害触发倒下，确认回入口、满血以及油 / 星 / 灯保留。截图与结果记录包含此独立战斗场景。
- 画布 / HUD / 对话框均在窗口内，PC 不显示触屏按钮；窗口缩放到 820×500 再恢复，携油进度不变。
- 携油后保存 → 整页刷新 → 继续，恢复携油；点灯后保存 → 整页刷新 → 继续，恢复灯柱与开启的门、油已消耗。
- 带油进入第一张联动棋盘，实际 E 旋镜并核对只改变自身与搭档两面、G / 鼠标按钮撤销、F 重置、鼠标点击镜面（含镜面上缘命中）；期间核对玩家 / 敌人 / HP / 能量冻结。未完成时 Esc 退出，确认没有耗油或开门，保存并整页刷新后恢复旋镜；用方向键选中另一面镜子并按 E，再用实际鼠标点击完成剩余联动操作，最后 E 确认点灯。三张棋盘的最短解 3/3/8 次、顺序错误、挡板、联动不可达与完整通关另有回归覆盖。
- 四个场景均可三灯 / 四星通关，第二关结算停播音乐；源存档键的哨兵值始终未被改写。
- 完整入口将真实第一关通关档转换为旧版 `current:1` 形式；整页刷新后可继续生日会，再进星光门进入第二关。
- 离线场景不请求外部字体或后端，第二关的背景 / 动作 / 音乐和对话可工作；页面 / 控制台无异常。

仓库回归：`npm ci`、55 份 JS 语法、14 套 Node 检查与第一 / 二关单关校验通过；全量仍有尚未制作关 3–6 等 42 项错误 / 0 警告。打包流程与验收脚本均为本地操作，没有提交、推送或更改部署。

这属于当前 Linux PC Chrome 的自动化浏览器验收；没有宣称已在 Windows、macOS 或其他浏览器人工试玩。用户的手感、画面与音乐反馈仍以打开包后的实际体验为准。
